# 失败态样例：品牌内容策略校验

## 输入异常

当输入为空、格式无效或评论语料被截断时，校验器应拒绝，不得凭空生成洞察。例如用户只贴了 3 条评论，或 brief 缺少产品/受众字段。

下一步：提示用户粘贴至少 200 条评论语料或一份完整 brief，并给出示例格式；仍为空则停止，不进入洞察环节。

## 依赖不可达

外部 API 超时、引用文件缺失或网络不可达时，聚类与意象提取无法完成；品牌资料文件不存在时也不能猜。

下一步：改用本地缓存样本；没有缓存就输出“待补数据”并停止，不编造需求或达人画像。恢复后从断点重跑，不重复已完成的步骤。

## 权限被拒

读取品牌资料、历史投放数据或飞书 Base 时权限被拒、凭据失效或目录只读。

下一步：请用户导出 Markdown/CSV 或开通只读权限后重试；不要提升权限，也不要把只读文件直接写成结论。若用户不授权，改用公开资料并在报告里标注“未读取内部数据”。
